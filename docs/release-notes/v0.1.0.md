Primera versión de prueba de BatteryTray. *First preview release.*

## Qué incluye

- Batería de dispositivos Bluetooth (los que Windows ya conoce, y dispositivos BLE con el servicio estándar de batería) y del propio portátil.
- Un icono por dispositivo en la bandeja (o uno solo con el nivel más bajo), con porcentaje o icono del dispositivo.
- Panel al estilo Windows 11, ventana de ajustes, aviso de batería baja, inicio con Windows.
- Español e inglés. Modo demostración para probarla sin dispositivos.

## Instalar

1. Descarga `BatteryTray-0.1.0-win-x64.zip` (o `win-arm64` para procesadores ARM).
2. Descomprímelo en una carpeta fija, por ejemplo `%LOCALAPPDATA%\Programs\BatteryTray`.
3. Abre `BatteryTray.exe`. El ejecutable aún no está firmado: si sale el aviso de SmartScreen, pulsa *Más información → Ejecutar de todas formas*.

Puedes comprobar la descarga con `SHA256SUMS.txt` (`Get-FileHash .\BatteryTray-0.1.0-win-x64.zip`).

## Si algo falla

*Ajustes > Avanzado > Copiar diagnóstico* y abre un aviso con el informe. ¡Gracias por probarla!
